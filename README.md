# 🤖 SRIT Help Chatbot

Welcome to the **SRIT Help Chatbot**, your friendly virtual assistant for **Srinivasa Ramanujan Institute of Technology (SRIT)**! 💬  
This chatbot helps students and visitors quickly find answers about the college — including **faculty, courses, facilities, and more.**

---

## 🚀 Features

- 💡 Instant answers for common SRIT-related questions  
- 🧠 Uses NLP-style keyword matching for accurate responses  
- 📚 Built with **Python**, **Streamlit**, and **Pandas**  
- 🌐 Deployed online using **Streamlit Cloud**
